# Wi-Fi and DNS Connectivity Issues

Symptoms:
- User is connected to Wi-Fi but cannot access websites
- Websites fail to load or report DNS errors
- Internal hostnames cannot be resolved
- Internet works by IP address but not hostname

Suggested investigation:
- Verify Wi-Fi connectivity and signal strength
- Check the device's DNS configuration
- Test DNS resolution using nslookup or dig
- Try reaching a known service by IP address
- Flush the local DNS cache
- Determine whether other users on the network are affected
