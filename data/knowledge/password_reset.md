# Password Reset and Account Access

Symptoms:
- User cannot log in to their account
- Password is reported as incorrect or expired
- User may be locked out after multiple failed attempts
- User recently changed their password

Suggested investigation:
- Verify the user's identity
- Check whether the account is locked or disabled
- Check password expiration status
- Confirm the user is using the correct username
- Reset or unlock the account if appropriate

Typical assignment:
Identity and access management or service desk
